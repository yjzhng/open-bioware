Overview

ChemSketcher is a desktop molecule sketchpad built on EPAM Ketcher, paired with an interactive table that computes physicochemical properties with RDKit as you draw. Sketch a structure or paste a SMILES string and the numbers appear beside it, with no round-trip to a web service.

Every distinct molecule on the canvas is recognised automatically and gets its own row, so you can compare a series side by side while you are still drawing it.

Features

  • Properties as you draw

    SMILES, molecular weight, logP, TPSA, hydrogen-bond donors and acceptors, ring counts, QED and InChIKey, computed live by RDKit.

  • Each molecule found automatically

    Draw several structures on one canvas and each distinct molecule is detected and given its own row in the table.

  • Reads and writes the usual formats

    Open and save .mol, .sdf, .ket and .smi files directly, so it fits whatever your pipeline already uses.

  • A layout you control

    Choose which properties to show, move or hide the table, and drag the divider to give the canvas the room it needs.
