Overview

ChemViewer opens a chemical library and lets you actually look at it: browse compounds in a virtualised table, inspect property distributions across the whole set, and compare one library against another. Depiction, descriptors and substructure search all run locally through RDKit's WebAssembly build.

It is built to stay light on a laptop. Small libraries are held in memory; anything over about 50 MB is queried on disk with DuckDB instead, and large sets are subsampled before analysis — with an option to compute full statistics when you want them.

Features

  • Reads the formats you already have

    CSV, SDF, SMILES and CXSMILES — drop the files into a folder named after the library and it appears.

  • Large files without the wait

    Libraries over 50 MB are queried on disk via DuckDB rather than loaded into memory, so opening one does not stall your machine.

  • See the whole library, not just rows

    Property statistics, UMAP embedding plots, and library-versus-library comparison alongside the compound table.

  • Sketch to search

    An embedded Ketcher canvas lets you draw a substructure and filter the library by it.
