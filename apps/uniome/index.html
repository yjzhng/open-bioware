Overview

UniOme brings together the annotation you would otherwise chase across a dozen web databases — per-gene annotation, protein and RNA structure and features, interactions, regulation and pathways — and puts it in one browser that runs on your own machine. There is no database server to install and no network round-trip: everything is served from local files.

Four organisms ship today: Escherichia coli K-12, Mycobacterium tuberculosis H37Rv, Staphylococcus aureus NCTC 8325 and Bacillus subtilis 168. More are added over time, and the data-build scripts live in the repository so a new organism can be ported.

Features

  • Around 30 databases, one interface

    Annotation integrated from roughly thirty external biological databases, cross-linked per gene instead of scattered across separate sites.

  • Works offline

    No database server, no account and no network dependency — the datasets ship with the app and are read straight from disk.

  • Structure and features in context

    Protein and RNA structure and features sit alongside the interactions, regulation and pathway data for the same gene.

  • Provenance you can audit

    Every dataset's origin, licence and primary citation is documented, so you can tell where any given value came from.
