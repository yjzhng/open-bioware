UniOme

A local-first annotation browser for prokaryotes — genes, structures, interactions, regulation and pathways, served entirely from files on your own machine.

  • Genomics & Annotation
  • macOS
  • MIT

UniOme brings together the annotation you would otherwise chase across a dozen web databases — per-gene annotation, protein and RNA structure and features, interactions, regulation and pathways — and puts it in one browser that runs on your own machine. There is no database server to install and no network round-trip: everything is served from local files.

Visit UniOme Download latest release
  • Around 30 databases, one interfaceAnnotation integrated from roughly thirty external biological databases, cross-linked per gene instead of scattered across separate sites.
  • Works offlineNo database server, no account and no network dependency — the datasets ship with the app and are read straight from disk.
  • Structure and features in contextProtein and RNA structure and features sit alongside the interactions, regulation and pathway data for the same gene.
  • Provenance you can auditEvery dataset's origin, licence and primary citation is documented, so you can tell where any given value came from.

ChemSketcher

Draw a molecule and watch its physicochemical properties compute live — an open-source sketchpad with an RDKit property table built in.

  • Chemistry & Cheminformatics
  • macOS
  • MIT

ChemSketcher is a desktop molecule sketchpad built on EPAM Ketcher, paired with an interactive table that computes physicochemical properties with RDKit as you draw. Sketch a structure or paste a SMILES string and the numbers appear beside it, with no round-trip to a web service.

Visit ChemSketcher Download latest release
  • Properties as you drawSMILES, molecular weight, logP, TPSA, hydrogen-bond donors and acceptors, ring counts, QED and InChIKey, computed live by RDKit.
  • Each molecule found automaticallyDraw several structures on one canvas and each distinct molecule is detected and given its own row in the table.
  • Reads and writes the usual formatsOpen and save .mol, .sdf, .ket and .smi files directly, so it fits whatever your pipeline already uses.
  • A layout you controlChoose which properties to show, move or hide the table, and drag the divider to give the canvas the room it needs.

ChemViewer

Explore chemical libraries interactively — compound properties, distribution statistics and side-by-side comparison, all computed locally.

  • Chemistry & Cheminformatics
  • macOS
  • MIT

ChemViewer opens a chemical library and lets you actually look at it: browse compounds in a virtualised table, inspect property distributions across the whole set, and compare one library against another. Depiction, descriptors and substructure search all run locally through RDKit's WebAssembly build.

Visit ChemViewer Download latest release
  • Reads the formats you already haveCSV, SDF, SMILES and CXSMILES — drop the files into a folder named after the library and it appears.
  • Large files without the waitLibraries over 50 MB are queried on disk via DuckDB rather than loaded into memory, so opening one does not stall your machine.
  • See the whole library, not just rowsProperty statistics, UMAP embedding plots, and library-versus-library comparison alongside the compound table.
  • Sketch to searchAn embedded Ketcher canvas lets you draw a substructure and filter the library by it.
