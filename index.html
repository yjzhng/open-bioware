BioGrapher

Paste your data and make publication-ready plots, with significance brackets you drag into place.

  • Analysis & Visualisation
  • macOS
  • Windows
  • MIT

BioGrapher is a plotting app for biologists. Paste data into a spreadsheet grid, mark what the rows and columns mean, and it becomes a plot-ready table in one click.

Visit BioGrapher Download latest release
  • Ready to plot in one clickMark what the rows and columns mean, and the table is reshaped for plotting.
  • 20+ chart typesScatter, bar, box, violin, heatmap, 3D and survival plots, plus curve fitting for dose-response, Michaelis–Menten and binding.
  • Drag to add significanceDrag across the groups you want to compare to add significance brackets.
  • Editable exportsSVG exports stay editable in vector drawing programs such as Illustrator or Inkscape.

OmicExplorer

Explore proteomics and other omic data: build an analysis as a workflow of steps, then explore linked, interactive plots.

  • Analysis & Visualisation
  • macOS
  • Windows
  • MIT

Load your own data, or turn one raw export from DIA-NN, Spectronaut or MaxQuant into ready-to-use files with the guided import. Annotations such as GO, KEGG, Reactome and STRING are fetched for you.

Visit OmicExplorer Download latest release
  • Workflow editorChain steps such as Load data, Clean data and Compare on a canvas. Save the whole analysis in one project file.
  • Guided importTurn a raw DIA-NN, Spectronaut or MaxQuant export into data, samplesheet and metadata files. Annotations are fetched for you.
  • Built-in statisticsFiltering, imputation, normalisation and batch correction, then t-tests, ANOVA, contrasts and dose or time curve fits.
  • Linked plotsVolcano, heatmap, PCA, enrichment, STRING network and more. Hover or pin a gene to highlight it in every plot.

UniOme

Browse gene, protein, interaction and pathway data for bacteria, offline on your own computer.

  • Genomics & Annotation
  • macOS
  • MIT

UniOme brings together annotation from about 30 public databases in one app: genes, protein and RNA structures, interactions, regulation and pathways. All data is stored on your computer, so it works offline with no server or account.

Visit UniOme Download latest release
  • About 30 databases in one placeAnnotation from about 30 databases, linked gene by gene.
  • Works offlineNo server, account or internet connection needed. The data comes with the app.
  • Structure next to functionSee protein and RNA structures alongside interactions, regulation and pathways for each gene.
  • Clear data sourcesThe source, licence and citation of every dataset are documented.

prokDB

Build one gene annotation table for any prokaryote from NCBI, UniProt and KEGG, in a desktop app or on the command line.

  • Genomics & Annotation
  • macOS
  • MIT

Enter a taxonomy ID and prokDB merges NCBI RefSeq and GenBank genome features, UniProt protein annotation and KEGG pathways into one CSV table. It can also predict where each protein is located in the cell, using DeepLocPro on your computer.

Visit prokDB Download latest release
  • Four sources, one tableNCBI RefSeq, GenBank, UniProt and KEGG merged per gene, with every column documented.
  • Nothing to install firstOn first launch the app sets up its own Python. No conda or system Python needed.
  • Local localisation predictionDeepLocPro predicts subcellular localisation on your computer.
  • Resume and batch runsAn interrupted run continues where it stopped. Process many organisms from one CSV.

ChemViewer

Explore chemical libraries: compound tables, property statistics and library comparisons, all on your computer.

  • Chemistry & Cheminformatics
  • macOS
  • MIT

Open a chemical library to browse its compounds, see property distributions and compare it with other libraries. Structure drawing, descriptors and substructure search run locally with RDKit.

Visit ChemViewer Download latest release
  • Common file formatsCSV, SDF, SMILES and CXSMILES. Put the files in a folder named after the library.
  • Fast with large filesLibraries over 50 MB are read from disk, so they open without slowing your computer.
  • Library-level viewsProperty statistics, UMAP plots and side-by-side library comparison.
  • Draw to searchDraw a substructure and filter the library by it.

ChemSketcher

Draw a molecule and see its properties calculated as you draw.

  • Chemistry & Cheminformatics
  • macOS
  • MIT

ChemSketcher is a molecule drawing app built on Ketcher. As you draw, or paste a SMILES string, RDKit calculates properties in a table next to the canvas. Nothing is sent to a web service.

Visit ChemSketcher Download latest release
  • Live propertiesSMILES, molecular weight, logP, TPSA, H-bond donors and acceptors, rings, QED and InChIKey.
  • Several molecules at onceEach molecule on the canvas is detected and listed separately.
  • Standard file formatsOpen and save .mol, .sdf, .ket and .smi files.
  • Flexible layoutChoose which properties to show, and move, hide or resize the table.
