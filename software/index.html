Other free academic softwares

Powerful open-source tools from the academic community. A collection of my personal favourites.

Imaging & Microscopy 1

  • Fiji (ImageJ)

    Imaging & Microscopy

    The reference image-analysis platform for biology — ImageJ bundled with hundreds of curated plugins for segmentation, registration, tracking and stitching.

    • macOS
    • Windows
    • Linux
    GPL-3.0 Website Source

  • PyMOL (Open Source)

    Structures & Molecules

    The molecular graphics system behind a large share of published structure figures, in its community-maintained open-source build.

    • macOS
    • Windows
    • Linux
    BSD-like Website Source

  • UCSF ChimeraX

    Structures & Molecules

    Molecular visualisation built for large structures, cryo-EM maps and publication-quality renders, from the team behind Chimera.

    • Windows
    • Linux
    Free for academic use Website Source

    Ketcher

    Browser-based chemical structure sketcher for drawing molecules and reactions, with SMILES and MOL import and export.

    • Web
    Apache-2.0 Website Source

    Structures & Molecules

    Annotates engineered plasmids automatically — paste a sequence and get back labelled features, ready to check or export.

    • Web
    • macOS
    • Windows
    • Linux
    GPL-3.0 Website Source
